# Figma snapshots — public build input

The token pipeline builds from **public snapshots**, one per component capture (ADR 0011, ADR 0012).
Each one is derived from a manual, read-only Figma capture that stays private.

- `chavosh-<component>.snapshot.public.json` — generated by `build/sanitize-snapshot.mjs` from the raw capture:
  Figma file, component and library style keys removed; style IDs replaced by `style:<type>/<name>`; everything
  else unchanged. Never edited by hand.
- `chavosh-<component>.snapshot.public.provenance.json` — generated: public SHA-256/size, raw capture attestation,
  sanitizer version, transformation counts and the capture record.

Configured captures: see `source/export-config.json`.
- `publicSnapshots` — released components, built into DTCG and CSS: Button (29 Sep 2026, raw SHA-256
  `adecb1cc8587634f057eb4bddb34a6a789012d65340f08cdd92dc81abe6b0a52`, frozen and never re-captured) and Link
  (30 Sep 2026, raw `aea3ff36c54d1096572d6cb8604dfd70632f3e7656b326c4c14da2c5b7c7bab4`) and Checkbox (30 Sep 2026, raw
  `a18ff7ab351c6f865c845621173f62d4bea3cefa39daf19d35f1a382f38f70a7`) and Radio (30 Sep 2026, raw
  `081685a52695d4c779006db16aedb358fd5c27cf513998abba21ff7995c77402`) and Switch (30 Sep 2026, raw
  `25f2859b173fcc0a7a2ef7b9d985d7d4d562c809fc7ed260ee5af4e2ef3c6e1e`).
- `stagedSnapshots` — recorded canonical captures of components not released yet (30 Sep 2026): Text Field. They pass the provenance gate and the consistency check but produce no tokens until their milestone
  (ADR 0013).
Captures must be mutually consistent: a variable shared by two captures must be identical in both.

## Capture procedure (exporter plugin v0.4.0, extractor v0.3.0)
1. `npm run bundle:exporter` (`tools/figma-exporter/dist-plugin/code.js` is verified fresh by `npm run verify`).
2. Figma **desktop**, design editor (not Dev Mode) → open *Chavosh Financial — Design System* → **Components** page
   (every capture target lives there; the plugin never switches pages).
3. **Plugins → Development → Import plugin from manifest…** → `tools/figma-exporter/manifest.json`, then run
   **Chavosh read-only token exporter v0.4.0**.
4. The plugin lists one entry per capture target (Link, Text Field, Checkbox, Radio, Switch) with its summary.
   Any ERROR entry: report it, do not adjust anything.
5. **Download** each file (`chavosh-<component>-figma-snapshot.json`). Do not open-and-save or reformat them.
   Version history must show no new version attributable to the run.
6. Keep the raw files private (never in this repository), then derive each public snapshot:
   `node packages/tokens/build/sanitize-snapshot.mjs <raw.json> <raw-capture-record.json> packages/tokens/snapshots/figma/chavosh-<component>.snapshot.public.json`
7. `npm run build` and `npm run verify -- --strict` (optionally with `CHAVOSH_RAW_SNAPSHOT=<raw file or folder>` to
   re-derive and compare byte-for-byte).
