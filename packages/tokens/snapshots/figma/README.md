# Figma snapshot — public build input

The token pipeline builds from a **public snapshot** derived from a manual, read-only Figma capture (ADR 0011).

- `chavosh-button.snapshot.public.json` — generated by `build/sanitize-snapshot.mjs` from the raw capture: Figma file,
  component and library style keys removed; style IDs replaced by `style:<type>/<name>`; everything else unchanged.
  Never edited by hand.
- `chavosh-button.snapshot.public.provenance.json` — generated: public SHA-256/size, raw capture attestation
  (SHA-256 `adecb1cc8587634f057eb4bddb34a6a789012d65340f08cdd92dc81abe6b0a52`, 490 808 bytes), sanitizer version,
  transformation counts and the capture record (Button `20:2`, exporter 0.3.0, captured 29 Sep 2026).

The raw capture itself is private and is not part of this repository.

## Capture procedure (exporter v0.3.0)
1. `npm run bundle:exporter` (`tools/figma-exporter/dist-plugin/code.js` is verified fresh by `npm run verify`).
2. Figma **desktop**, design editor (not Dev Mode) → open *Chavosh Financial — Design System* → **Components** page
   (the plugin reads the Button set `20:2` there and never switches pages).
3. **Plugins → Development → Import plugin from manifest…** → `tools/figma-exporter/manifest.json`, then run
   **Chavosh read-only token exporter v0.3.0**.
4. Check the summary (`Button (60 variants, … bindings)`, 2 text styles `label/md`, `label/sm`), then **Download snapshot**.
   Do not open-and-save or reformat it. Version history must show no new version attributable to the run.
5. Keep the raw file and its capture record privately, then derive the public snapshot:
   `node packages/tokens/build/sanitize-snapshot.mjs <raw.json> <raw-capture-record.json> packages/tokens/snapshots/figma/chavosh-button.snapshot.public.json`
6. `npm run build` and `npm run verify -- --strict` (optionally with `CHAVOSH_RAW_SNAPSHOT=<raw.json>` to re-derive
   and compare byte-for-byte).
