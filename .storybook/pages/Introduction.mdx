# Chavosh Financial Design System

Coded components of the Chavosh Financial Design System, rendered from the production packages:
**`@chavosh/tokens`** (design tokens generated from Figma) and **`@chavosh/react`** (React components).

This Storybook shows **implementation and behaviour**: the real components, their API, states, brand behaviour and accessibility behaviour.
Broader guidance — principles, foundations, content, accessibility standards, governance and the design-to-code process — lives in the design-system documentation site (Zeroheight).

## What's here
- **Foundations / Design tokens** — how components consume tokens, brands and breakpoints.
- **Components / Button** — Button v1 (labels only): triggers actions.
- **Components / Link** — Link v1 (standalone, labels only): navigates to a destination or resource.

## Using the toolbar
- **Brand** — switch between Financial (default) and Invest. Components follow the brand context through CSS custom properties.
- **Viewport** — preview at Mobile (375), Tablet (768) or Desktop (1024).
- **Accessibility** panel — automated checks for each story. Automated results are not a conformance claim.
